# Ember

Example [Ember](https://emberjs.com/) app. Ember.js is a JavaScript framework for building ambitious web applications with strong conventions.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | on |
| Project directory | `/` |
| Output directory | `/dist` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run start

# build for production with minification
npm run build
```
